WHAT IS ANSIBLE?
Ansible is an automation tool for configuration
management and server administration.

1. IMPORTANT TERMS
------------------
Inventory = List of managed hosts
Playbook = YAML automation file
Task = Individual action
Module = Performs an operation
Role = Reusable automation structure
Handler = Runs when notified

2. COMMANDS
-----------
ansible --version
ansible-inventory --list
ansible all -i inventory -m ping
ansible-playbook playbook.yml

3. EXAMPLE INVENTORY
--------------------
[webservers]
192.168.1.10
192.168.1.11

4. EXAMPLE PLAYBOOK
-------------------
---
- name: Install Nginx
  hosts: webservers
  become: true

  tasks:
    - name: Install Nginx
      apt:
        name: nginx
        state: present

---------------------
